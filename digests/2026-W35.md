## 3. 三命题坐标 · 本周落点

> 每周读完，回到这三轴各记一句：本周哪根轴的证据在增厚？哪根还空着？

- **命题一｜Jagged Intelligence —— 测量对象长什么样（锯齿状，旧尺子量不了）**
  - 本周这根轴证据在显著增厚：Qwen3.8-Flash-Next 与 GLM-5.3-Flash 两款稀疏/轻量模型同日霸榜 HN、HF、PH，Simon 本地实测确认「更少激活参数、更强表现」；张小珺领读 Kimi K3 技术报告——注意力美学、多教师蒸馏、开源 MoE，证明 W34 的「后训练接棒」正具体化为蒸馏与稀疏架构；卫诗婕 EP.84 把测量从 demo 拉回交付——49 家央企采买进场的 WRC，「订单真实性」成为具身智能的诚实标尺。
  - 还空着：单个模型内部锯齿（W34 的「过度思考」）本周没有新的系统性实测，Flash 模型的锯齿形状待补。

- **命题二｜Intention Layer —— 人类守在意图层，不是执行层**
  - 本周最厚的轴，且从「守住」进入「工程方法」：Simon「More than just code review」——用好编码智能体的关键是引导方向 + 验证结果，不是逐行审查；Sachin Rekhi 回归即给出组织级答案——Compounding OS：agentic 平台标准化 + 共享技能库 + 机器可读的公司上下文；Ryan Carson 一个月烧 2 万美元跑 15 个 Devin、靠手写清单统管全局；swyx 引 Lovable CTO「SaaS 的未来是 agent 能使用的应用」——意图层的接口正变成产品的设计约束。
  - 还空着：意图层「验证」环节的方法论仍单薄——引导有了，验证结果的好做法还没有范本。

- **命题三｜Metacognition —— 边界会不会移动，取决于判断力能否被拿走**
  - 本周证据分散但两头都有进展：人类侧，Eva「The Perfectionist's Paradox」给出可操作的元认知干预——「测试你恐惧的预言」打破完美主义瘫痪；Dan Williams 断言关于 AI 的大多数重大问题不是 AI 问题——判断力的素材在学科之外。系统侧，「Breaking Claude Code Opus 5 Auto Mode」证明自动保护模式仍可被诱导——边界不天然安全，沙箱仍是必需品；FT 报道旗舰模型定价阻碍采用——经济校准继续（续 W34 信号 B）。
  - 还空着：「判断力被拿走」的正面实证（人类技能退化的测量）依然缺席，这根轴本周是修补而非增厚。
